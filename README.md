AI Computer Vision Projects

# Overview
This repository contains beginner-to-intermediate level AI vision projects focused on:
- Face Detection
- Hand Tracking
- Finger Counting
- Pose Detection
These projects helped me learn real-time computer vision, landmark tracking, and AI-based interaction systems.

# Projects Included
## 1. Face Detection
Real-time face detection using webcam and MediaPipe Face Detection.
### Features
- Detects human faces in real time
- Facial landmark points
- Lightweight and fast
- 
### Run
py -3.10 face.py

2. Hand Tracking
Tracks hand landmarks and finger positions using MediaPipe Hands.  
Features
Real-time hand tracking
21 hand landmark points
Finger connection visualization
Run
py -3.10 hand.py
3. Finger Counter

Counts raised fingers using hand landmark analysis.

Features
Real-time finger counting
Hand landmark tracking
Gesture-based interaction
Run
py -3.10 finger_counter.py
4. Pose Detection

Full body pose estimation using MediaPipe Pose.

Features
Skeleton tracking
Body landmark detection
Real-time movement tracking
Run
py -3.10 pose.py
